# ゲームフェイズと自分対象時の特殊ルール仕様書

このドキュメントでは、`GodFieldAI` におけるゲームフェイズ（状態）の定義と遷移、および自分自身をターゲットにした場合の特殊な取引・効果解決ルール、さらにHP 0時のアクション制限、複数回攻撃、ターン終了解決の特殊フローについてまとめます。

---

## 1. ゲームフェイズの定義 (`GamePhase`)

C++エンジンは、以下のフェイズ（GamePhase型）を用いてプレイヤーの手番やゲーム状態の遷移を制御しています。

| フェイズ (GamePhase) | 概要説明 | アクション可能なプレイヤー | 次の遷移先フェイズ |
| :--- | :--- | :--- | :--- |
| `PHASE_GUARDIAN` | 守護神の効果・行動を解決するフェイズ。 | 自動処理 (Auto-advanced) | `PHASE_MAIN` |
| `PHASE_MAIN` | ターン開始時のメインフェイズ。「祈る」「捨てる」「両替」および「攻撃/奇跡/売る/買う/雑貨」カードの使用が可能。 | 手番プレイヤー (Active) | カードの使用に応じて変化 |
| `PHASE_MAIN_TARGET_SELECT` | 使用した「売る」「買う」「雑貨」カードの対象（自分 / 相手）を選択するフェイズ。 | 手番プレイヤー (Active) | 選択した対象により変化（ミラー確認、または即時解決） |
| `PHASE_ATTACK_PLUS` | 単体攻撃カード発動時、追加で「攻撃のプラス」カードや「＜蜃気楼＞」を選択するフェイズ。 | 手番プレイヤー (Active) | 相手対象なら `PHASE_DEFENSE`、自分対象なら `PHASE_END`、＜蜃気楼＞使用時は `PHASE_GROUP_WEAPON` |
| `PHASE_GROUP_WEAPON` | 単体武器に＜蜃気楼＞をプラスした際（この時のみ追加の蜃気楼や精霊系カード等を選択可能）、または最初から全体攻撃武器である場合（追加選択不可でそのまま対象を決定）の全体武器攻撃フェイズ。 | 手番プレイヤー (Active) | 相手対象（ターゲットは相手全体 `OPP` のみ）決定で `PHASE_DEFENSE` |
| `PHASE_DEFENSE` | 相手から受けた物理/属性攻撃に対して防御や反射アクションを選択するフェイズ。 | 防御プレイヤー (Defender) | `PHASE_END` |
| `PHASE_MIRACLE_PLUS` | 単体奇跡カード発動時、追加で「消費MPを0にする」カード（精霊系）などを選択するフェイズ。 | 手番プレイヤー (Active) | 相手対象なら `PHASE_MIRACLE_DEFENSE`、自分対象なら `PHASE_END` |
| `PHASE_GROUP_MIRACLE_PLUS` | 全体奇跡の発動時、追加で「精霊系」カード等を選択する全体奇跡攻撃フェイズ。 | 手番プレイヤー (Active) | 相手対象（ターゲットは相手全体 `OPP` のみ）決定で `PHASE_MIRACLE_DEFENSE` |
| `PHASE_MIRACLE_DEFENSE` | 相手から受けた奇跡に対して、反射や阻止アクションを選択するフェイズ（物理/属性防御と異なり、奇跡防具の防御力数値による減算計算は行われません）。 | 防御プレイヤー (Defender) | `PHASE_END` |
| `PHASE_SELL_SELECT` | 「売る」カード使用後、自分の手札から売り出したいアイテムカードを選択するフェイズ。 | 手番プレイヤー (Active) | `PHASE_MAIN_TARGET_SELECT` |
| `PHASE_SELL_SELECT_MIRROR` | 相手にアイテムを売りつける際、買い手側が「スーパーミラー」で反射するか「受諾(CONFIRM)」するかを選択するフェイズ。 | 買い手プレイヤー (Defender) | `PHASE_END` (受諾時) または 反射され入れ替わった `PHASE_SELL_SELECT_MIRROR` (反射時) |
| `PHASE_BUY` | 相手の手札から提示されたカードをお金を払って購入するか（YES/NO）を選択するフェイズ。 | 買い手プレイヤー (Active) | `PHASE_END` |
| `PHASE_BUY_SELECT_MIRROR` | 「買う」カード使用時、売り手側が「スーパーミラー」で反射するか「受諾(CONFIRM)」するかを選択するフェイズ。 | 売り手プレイヤー (Defender) | `PHASE_BUY` (受諾時)、反射され入れ替わった `PHASE_BUY_SELECT_MIRROR` (反射時)、または `PHASE_END` (取引失敗時) |
| `PHASE_SUNDRY_SELECT_MIRROR` | 相手に「雑貨」カードを使用する際、対象側が「スーパーミラー」で反射するか「受諾(CONFIRM)」するかを選択するフェイズ。 | 対象プレイヤー (Defender) | `PHASE_END` (受諾時) または 反射され入れ替わった `PHASE_SUNDRY_SELECT_MIRROR` (反射時) |
| `PHASE_EXCHANGE_HP` / `PHASE_EXCHANGE_MP` | 「両替」カード使用時、HPまたはMPに充当する数値を決定・入力するフェイズ。 | 手番プレイヤー (Active) | `PHASE_END` |
| `PHASE_DISCARD` | 「捨てる」アクションを選択した際、捨てる手札を選択するフェイズ。 | 手番プレイヤー (Active) | `PHASE_END` |
| `PHASE_END` | ターン終了時のクリーンアップ処理（風邪・熱・地獄のダメージ適用など）を行うフェイズ。 | 自動処理 (Auto-advanced) | 次のプレイヤーの `PHASE_MAIN` |

## 2. 自分対象（自分自身をターゲットにした場合）の特殊挙動

自分自身を対象にしたアクション（自傷、自売り、自己買いなど）は、防御やカウンター、合意形成のための割り込みフェイズをスキップして即時に効果が解決されます。

### A. 「売る」で自分を対象にした場合
- **遷移**: 「売る」使用 -> 売りたい手札を選択 -> **対象に「自分」を選択**。
- **解決ルール**:
  - 買い手からのミラー確認フェイズ（`PHASE_SELL_SELECT_MIRROR`）は**完全にスキップ**されます。
  - 対象に「自分」を選択したステップ内で、即座に売買決済が処理されます。
  - **支払いの解決**: プレイヤー自身が、そのカードの売値（Price）分の金額を「所持金 -> MP -> 残りHP」の優先順位で支払います（HPから支払った分はダメージになります）。
  - **代金の受け取り**: プレイヤー自身に売値分のお金（Money）が支払われます（上限99）。
  - **カードの移動**: 売却されたカードは自分の手札から一度消去された後、自分の空きスロットに戻されます（空きがない場合はランダムに1枚上書きされます）。
  - 処理終了後、即座に `PHASE_END`（ターン終了）に遷移します。

### B. 「買う」で自分を対象にした場合
- **遷移**: 「買う」使用 -> **対象に「自分」を選択**。
- **解決ルール**:
  - 自分自身からカードを購入する取引そのものは発生しません。
  - 使用者の手札からランダムに1枚が選択され、相手プレイヤーに対して公開状態（`is_known_to_opp = true`）になります。
  - お金やMPの支払いや、カードの移動処理などは一切発生しません。
  - 処理終了後、即座に `PHASE_END`（ターン終了）に遷移します。

### C. 「雑貨」で自分を対象にした場合
- **遷移**: 雑貨カード使用 -> **対象に「自分」を選択**。
- **解決ルール**:
  - 相手への使用時に発生するミラー反射等の確認フェイズは**スキップ**されます。
  - 雑貨カードの効果（ステータス回復、病気治療など）が即座に使用者自身に適用されます。
  - 処理終了後、即座に `PHASE_END`（ターン終了）に遷移します。

### D. 「攻撃 / 奇跡」で自分を対象にした場合（自傷）
- **遷移**: 攻撃/奇跡の発動 -> **対象に「自分」を選択**。
- **解決ルール**:
  - 相手ターン時の防御リアクションフェイズ（`PHASE_DEFENSE`, `PHASE_MIRACLE_DEFENSE`）は**スキップ**されます。
  - 攻撃力や奇跡の効果（ダメージやステータス異常）が即座に使用者自身に適用されます。
  - 処理終了後、即座に `PHASE_END`（ターン終了）に遷移します。

## 3. 「売る」に対するスーパーミラー反射時の特殊挙動

取引（売買）フェイズ特有の複雑な挙動として、相手から提示された「売る」のアクションをスーパーミラーで反射した場合のルールを記述します。

- **遷移**: 
  1. プレイヤーAが手札カードXをプレイヤーBに売ろうとする (`PHASE_SELL_SELECT` -> `PHASE_MAIN_TARGET_SELECT`にて対象にBを選択)
  2. Bは `PHASE_SELL_SELECT_MIRROR` において「スーパーミラー」を使用
  3. **反射の発生**: ロール（売り手/買い手）がスワップされ、アクターがプレイヤーA（元の売り手）に交代。フェイズは `PHASE_SELL_SELECT_MIRROR` のまま維持されます。
- **解決ルール**:
  - **対象カードの固定**: 反射された場合であっても、売買される対象カードは「元の売り手Aが売ろうとしていたカードX」で**固定**されます。反射側（B）が新たに自分の手札からカードを選択し直す必要はありません。
  - **手札制限の免除**: 反射側（B）はカードを売りつける立場（売り手）になるため、自分の手札が一杯であっても何ら問題なく反射が機能します。
  - **再反射**: アクターとなったAは、さらにスーパーミラーを出して反射し返すことができます。
  - **決済**: 最終的にミラーを使用せずに受諾（`ACTION_CONFIRM`）された場合、その時点での「売り手」が代金を受け取り、「買い手」が代金を支払いカードXを引き取ります。
  - **アセットと手札数の推移**:
    - **買い手（元の売り手A）**: 代金を支払い（お金 - 価格）、売ろうとしていたカードXを再び自分の手札（空きスロット）に引き取ります。また、使用した「売る」カードのスロットは新しいカードがドロー補充されます。結果として、Aの手札総数は変化しません。
    - **売り手（元の買い手B）**: スーパーミラーにより売り手にスワップされたため、代金を受け取ります（お金 + 価格）。カードXはAの手元に戻るため、Bの手札には移動しません。また、Bが消費した「スーパーミラー」のスロットには新しいカードがドロー補充されます。結果として、Bの手札総数は変化しません。

## 4. 「買う」に対するスーパーミラー反射時の特殊挙動

相手から提示された「買う」のアクションをスーパーミラーで反射した場合のルールを記述します。

- **遷移**: 
  1. プレイヤーAがプレイヤーBに対して「買う」を使用する（`PHASE_MAIN_TARGET_SELECT` にて対象にBを選択）。
  2. Bは `PHASE_BUY_SELECT_MIRROR` において「スーパーミラー」を使用。
  3. **反射の発生**: ロール（買い手/売り手）がスワップされ（Bが買い手、Aが売り手となる）、アクターがプレイヤーA（元の買い手）に交代。フェイズは `PHASE_BUY_SELECT_MIRROR` のまま維持されます。
- **解決ルール**:
  - **再反射**: アクターとなったAは、さらにスーパーミラーを出して反射し返すことができます（その場合、再度ロールがスワップされてBに交代します）。
  - **合意・決済**: 最終的にミラーを使用せずに受諾（`ACTION_CONFIRM`）された場合、その時点での「買い手（アクターの相手側）」がカードを購入する権利を得て、フェイズが `PHASE_BUY` に移行します。
    - 受諾したプレイヤー（売り手）の手札からランダムに1枚のカードが公開され提示されます。この際、すでに使用中（`is_used = true`）のカードやコマンドカードは選択対象から除外されます。
    - 買い手は、提示されたカードに対して「購入する（YES）」か「購入しない（NO）」を選択し、取引が決済されます。

## 5. 「雑貨」に対するスーパーミラー反射時の特殊挙動

相手から使用された「雑貨（天国草、カラス、悪魔など）」のアクションをスーパーミラーで反射した場合のルールを記述します。

- **遷移**: 
  1. プレイヤーAがプレイヤーBに対して雑貨カードを使用する（`PHASE_MAIN_TARGET_SELECT` にて対象にBを選択）。
  2. Bは `PHASE_SUNDRY_SELECT_MIRROR` において「スーパーミラー」を使用。
  3. **反射の発生**: ロール（攻撃側/防御側）がスワップされ（Bが攻撃側、Aが防御側となり、BがAに向けて雑貨を使う形になる）、アクターがプレイヤーAに交代。フェイズは `PHASE_SUNDRY_SELECT_MIRROR` のまま維持されます。
- **解決ルール**:
  - **再反射**: アクターとなったAは、さらにスーパーミラーを出して反射し返すことができます（その場合、再度ロールがスワップされてBに交代します）。
  - **合意・決済**: 最終的にミラーを使用せずに受諾（`ACTION_CONFIRM`）された場合、その時点での「防御側（アクター）」に対して、元の雑貨カードの効果が適用されます。
    - 適用後、両者の仮置きカードはリセットされ、`PHASE_END` に遷移してターンが終了します。

## 6. HPが0の時の防御・ミラー反応制限と複数攻撃の解決

実機ルールに準拠し、HPが0になったプレイヤーに対するアクションの制限および複数回攻撃の解決ルールを以下のように規定します。

### A. HP 0 時のアクション制限
攻撃を受けてHPが0（またはそれ以下）になったプレイヤーは、仮置き場での防御やミラー反射を行うことができなくなります。
- 以下のフェイズにおいて、HPが0になったプレイヤーが選択可能な唯一の合法アクションは **`ACTION_CONFIRM`（パス / 確認）** のみに制限されます。
  - `PHASE_DEFENSE` (物理/属性防御フェイズ)
  - `PHASE_MIRACLE_DEFENSE` (奇跡防御フェイズ)
  - `PHASE_SUNDRY_SELECT_MIRROR` (雑貨ミラー確認フェイズ)
  - `PHASE_SELL_SELECT_MIRROR` (売るミラー確認フェイズ)
  - `PHASE_BUY_SELECT_MIRROR` (買うミラー確認フェイズ)
- 防具を手札から出したり、スーパーミラーを置いて反射・無効化することはできません。

### B. 複数攻撃（蜃気楼・乱弾武剣）の解決
- 「＜蜃気楼＞」の重ねがけや「乱弾武剣」の効果によって複数回攻撃（`remaining_attacks`）が予約されている場合、**途中でターゲット側のHPが0になったとしても残りのすべての攻撃はキャンセルされず、最後まで継続して実行**されます。
- この解決の間、HPが0の被攻撃側は上記「HP 0時のアクション制限」に基づき、すべての残余攻撃に対して `ACTION_CONFIRM` のみを行う形となり、ダメージを受け続けます。

## 7. 太陽のお守り（即時解決）と昇天弓（遅延解決）の挙動差

HPが0になった場合の救済カードである「太陽のお守り」と「昇天弓」は、解決タイミングに明確な違いが存在します。

- **太陽のお守り（即時解決）**:
  - プレイヤーがダメージを受けてHPが0になった瞬間、フェイズの途中（防御フェイズの解決中など）であっても手札に「太陽のお守り」があれば**即座に消費され、HP 10 で復活**します（即時復活: `run_immediate_revive`）。
  - 復活したため、残りの攻撃やターン終了時の死亡チェックはHP 10（生存状態）として継続されます。
- **昇天弓（ターン終了解決）**:
  - ダメージによってHPが0になった時点では、手札にある「昇天弓」は消費されず、反撃も行われません。
  - ターン終了フェイズ（`PHASE_END`）の最初のステップ（State 0）において、初めて手札の「昇天弓」がクリア（消費）され、反撃がキューイングされて発射されます。

## 8. ターン終了フェイズ（`PHASE_END`）の詳細解決フロー

ターン終了フェイズは、プレイヤーのアクション入力完了後に自動で走る解決プロセスです。
ただし、お守りでの復活や病気等のダメージのみのターン解決とは異なり、**「昇天弓の反撃発射」や「相手守護神の攻撃行動」が発生した場合は、防御入力待ちのために一時的に `PHASE_DEFENSE` や `PHASE_MIRACLE_DEFENSE` へと遷移し、C++ループを中断してユーザーの入力を待ちます。** 防御が解決されると、再び `PHASE_END` に戻って次のステップから処理が再開されます。

ターン終了解決は以下の **State 0 〜 5** の順に進みます。

### State 0: 死亡判定・太陽のお守り・昇天弓
HPが0のプレイヤーがいる場合、以下の順序で救済処理を再帰的にチェックします。
**【終末の時（Apocalypse）における遅延ルール】**
ターン数が150ターン以上に達した「終末の時（Apocalypse）」においては、State 0〜3 での死亡チェック（`run_death_check`）が**すべてスキップ（保留）**されます。生存しているプレイヤーのクリーンアップドロー（悪魔ドローなどを含む）がすべて完了した後の State 5 の最終段階で、まとめて一度だけ死亡判定が実行されます（これにより両者死亡による引き分けが発生しやすくなります）。以下は通常ターン時のフローです。

1. **太陽のお守りによる復活**:
   - 手札に「太陽のお守り」がある場合、それを消費（手札スロットは `CARD_EMPTY` になり、使用済みフラグ `is_used` が真となる）し、**HP 10 で即時復活**します。
   - 復活後、再度 State 0 の死亡チェックを再帰的に実行します。
   - 消費された「太陽のお守り」の手札枠は、最終段階（State 5）のクリーンアップ時に自動的に山札から新規ドロー補充されます。
2. **昇天弓による最後の反撃**:
   - 太陽のお守りを持っておらず、手札に「昇天弓」がある場合、**手札にある昇天弓の数だけ**「光属性・ATK 30・命中率 75%・全体攻撃」の反撃を予約（`pending_ascension_bows` にキューイング）します。
   - このときの攻撃力と命中率は、手札から通常の武器として撃つ場合（ATK 1・命中率 25%）と**意図的に異なります**（定数 `ASCENSION_BOW_TRIGGERED_POWER` / `ASCENSION_BOW_HIT_RATE`）。一方で全体攻撃かどうかはカードそのものの性質なので、カードマスタの `is_group_attack` をそのまま引き継ぎます。
   - 対象のスロットは空（`CARD_EMPTY`）になり、使用済みフラグ `is_used` が真になります（お守りと同様にターンエンド最終段階で新規補充されます）。
   - 保留中の昇天弓がある場合、そのうちの1発を発射（75%の確率で命中）します。
     - **命中した場合**: 相手の防御フェイズ（`PHASE_DEFENSE`、アクターは相手）へ移行し、C++の自動処理を一時中断します。
     - **命中しなかった場合**: 次の昇天弓があれば続けて発射判定を行います。

※**遅延判定ルール**: 待機側のプレイヤーのみが死亡している場合、手番プレイヤー（アクティブプレイヤー）のターン終了時の病気ダメージ処理（State 1, 2）が完了するまでゲーム終了を遅延します。手番プレイヤーが病気で死亡した場合は引き分け（Draw）となり、生き残った場合のみ State 3 で勝利終了します。

### State 1: 病気悪化判定
手番プレイヤー（ターンが終了した側、state.current_actor_id）に対し、現在かかっている病が **5% の確率で悪化**します。待機側のプレイヤーには悪化判定は行われません。
- **風邪 (Cold)** $\rightarrow$ **熱病 (Fever)**
- **熱病 (Fever)** $\rightarrow$ **地獄病 (Hell)**
- **地獄病 (Hell)** $\rightarrow$ **天国病 (Heaven)**
- **天国病 (Heaven)** $\rightarrow$ **悪化による死亡 (HP = 0, 発作)**
※悪化によって死亡したプレイヤー（自分）がいる場合、即座に State 0（お守り/昇天弓判定）が再帰起動します。この時、**ターン終了時の発作フラグ**（`heaven_seizure_occurred`）が真に設定されます（※終末の時はスキップ）。

### State 2: 病気ダメージ・回復処理
手番プレイヤー（state.current_actor_id）に対し、病気に応じたダメージ/回復が適用されます。待機側のプレイヤーはダメージ・回復を受けません。
- **風邪**: 1 ダメージ
- **熱病**: 2 ダメージ
- **地獄病**: 5 ダメージ
- **天国病**: 5 回復（上限 99 クランプ）
※**発作時スキップルール**: State 1 で天国病の自然悪化（発作）によって死亡していた場合、そのターン終了時の回復（+5）はスキップされ、お守りで復活した際の最終HPは 10 となります。ただし、メインフェイズ中に自分に「＜天国風＞」を使う等の攻撃（重ねがけ）によって発生した発作死亡はお守り復活後にターン終了時回復（+5）が通常通り適用され最終HP 15 となります（自然悪化による発作のみがスキップ対象となります）。

### State 3: 引き分け/勝敗の最終確定
State 0 〜 2 の一連の処理が終了した時点で、依然として HP が 0 のプレイヤーがある場合、ゲームを終了します（※終末の時はスキップ）。
- 両者同時に HP 0 $\rightarrow$ 引き分け（`is_done = true`, 両者の報酬 `0.0f`）
- プレイヤー0のみ HP 0 $\rightarrow$ プレイヤー1の勝利（P0報酬 `-1.0f`, P1報酬 `1.0f`）
- プレイヤー1のみ HP 0 $\rightarrow$ プレイヤー0の勝利（P0報酬 `1.0f`, P1報酬 `-1.0f`）

### State 4: 相手守護神の行動
手番が終了したプレイヤーの相手（＝次に手番が渡るプレイヤー）に守護神（ID 1〜10）が憑いている場合、**25% の確率で行動**します。
攻撃行動が発生した場合は、被攻撃側の防御フェイズへと移行し、C++処理を一時中断します。
- **火星神 (Mars)**: 火属性攻撃（威力 5/10/15/20/25 のいずれか、全体攻撃または単体攻撃）。被攻撃側の防御フェイズ（`PHASE_DEFENSE`）へ移行。
- **水星神 (Mercury)**: 被攻撃側に状態異常「霧」を付与し、さらに水属性攻撃（威力 5/10/15/20 のいずれか）を放つ。
- **木星神 (Jupiter)**: 被攻撃側に状態異常「夢」を付与し、さらに木属性攻撃（威力 5/10/15 のいずれか）を放つ。
- **土星神 (Saturn)**: 土（石）属性攻撃（威力 10/15/20/25/30 のいずれか）。
- **天王神 (Uranus)**: 被攻撃側に状態異常「閃光」を付与し、さらに無属性攻撃（威力 5/10/15/20 のいずれか）を放つ。
- **冥王神 (Pluto)**: 闇属性攻撃（威力 5/10/15/20/25 のいずれか）。
- **海王神 (Neptune)**: 自分自身（守護神の主人）の HP (+15/+25) または MP (+10/+20) を回復、あるいは病気・災い状態を全快する支援行動。
- **金星神 (Venus)**: 「罰金」（被攻撃側のお金をドレインして自身に加算、威力3）または「わいろ」（相手にお金+5）の行動を行います。これらは共に防御フェイズ（`PHASE_DEFENSE`）を介して実行され、スーパーミラー等の雑貨（sundry）反射カードで反射可能です。「わいろ」が反射された場合は、お金+5は元の発動者側（金星神の主人）に加算されます。
- **地球神 (Earth)**: 新しく山札からカードをドローし、種類に応じて以下のように行動します。
  - 防具・奇跡・受動雑貨 $\rightarrow$ 自分の手札に加える。
  - 両替 $\rightarrow$ 自身の全ステータス（HP, MP, 所持金）を各値 99 以下でランダムに再配分。
  - 売る $\rightarrow$ 自分の手札からランダムな売却可能カード1枚を相手に売りつける（相手の `PHASE_SELL_SELECT_MIRROR` を起動。売れる手札がなければスキップ）。
  - 買う $\rightarrow$ 相手に購入を仕掛ける（相手の `PHASE_BUY_SELECT_MIRROR` を起動、相手受諾時は自分が `PHASE_BUY` で購入選択。相手に売れる手札がなければスキップ）。スーパーミラーで反射された場合は自分が売る側となる。
  - 武器 $\rightarrow$ 相手を物理攻撃（相手の `PHASE_DEFENSE` を起動）。
- **月神 (Moon)**: ランダムな属性（火/水/木/土/光/闇のいずれか）の奇跡攻撃（威力10）。被攻撃側の奇跡防御フェイズ（`PHASE_MIRACLE_DEFENSE`）へ移行。

### State 5: クリーンアップと手番移行
すべての処理が正常終了した場合：
1. **生存プレイヤーのみクリーンアップドロー**:
   - 生存している（`hp[p] > 0`）プレイヤーのみ、お守りや昇天弓等で消費された手札スロット（`is_used = true` で `CARD_EMPTY` のもの）に山札から新しいカード（終末の時であれば悪魔出現＆再ドローを伴う）が補充されます。
   - 死者のドローはスキップされます。
2. **【終末の時の最終死亡チェック】**:
   - 終末の時（Apocalypse）においては、ここで初めて両者のHPの死亡・勝敗チェック（`run_death_check`）が実行されます。
3. 初期化: `turn_end_state` を `0` にリセット、`heaven_seizure_occurred` フラグをリセット。
4. 手番交代: `current_turn` をインクリメントし、次の手番プレイヤー（`current_turn % 2`）に交代。
5. フェイズを `PHASE_MAIN` に設定し、新たなターンを開始します。
