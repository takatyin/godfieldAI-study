# ゲームフェイズと自分対象時の特殊ルール仕様書

このドキュメントでは、`GodFieldAI` におけるゲームフェイズ（状態）の定義と遷移、および自分自身をターゲットにした場合の特殊な取引・効果解決ルールについてまとめます。

---

## 1. ゲームフェイズの定義 (`GamePhase`)

C++エンジンは、以下のフェイズ（GamePhase型）を用いてプレイヤーの手番やゲーム状態の遷移を制御しています。

| フェイズ (GamePhase) | 概要説明 | アクション可能なプレイヤー | 次の遷移先フェイズ |
| :--- | :--- | :--- | :--- |
| `PHASE_GUARDIAN` | 守護神の効果・行動を解決するフェイズ。 | 自動処理 (Auto-advanced) | `PHASE_MAIN` |
| `PHASE_MAIN` | ターン開始時のメインフェイズ。「祈る」「捨てる」「両替」および「攻撃/奇跡/売る/買う/雑貨」カードの使用が可能。 | 手番プレイヤー (Active) | カードの使用に応じて変化 |
| `PHASE_MAIN_TARGET_SELECT` | 使用した「売る」「買う」「雑貨」カードの対象（自分 / 相手）を選択するフェイズ。 | 手番プレイヤー (Active) | 選択した対象により変化（ミラー確認、または即時解決） |
| `PHASE_ATTACK_PLUS` | 単体攻撃カード発動時、追加で「攻撃のプラス」カードや「＜蜃気楼＞」を選択するフェイズ。 | 手番プレイヤー (Active) | 相手対象なら `PHASE_DEFENSE`、自分対象なら `PHASE_END`、＜蜃気楼＞使用時は `PHASE_GROUP_WEAPON` |
| `PHASE_GROUP_WEAPON` | 全体攻撃武器の発動時、または単体武器に＜蜃気楼＞をプラスした際、追加で「精霊系」カード等を選択する全体武器攻撃フェイズ。 | 手番プレイヤー (Active) | 相手対象（ターゲットは相手全体 `OPP` のみ）決定で `PHASE_DEFENSE` |
| `PHASE_DEFENSE` | 相手から受けた物理/属性攻撃に対して防御や反射アクションを選択するフェイズ。 | 防御プレイヤー (Defender) | `PHASE_END` |
| `PHASE_MIRACLE_PLUS` | 単体奇跡カード発動時、追加で「消費MPを0にする」カード（精霊系）などを選択するフェイズ。2枚以上の攻撃奇跡が重なった場合は `PHASE_ATTACK_PLUS` に遷移。 | 手番プレイヤー (Active) | 相手対象なら `PHASE_MIRACLE_DEFENSE`、自分対象なら `PHASE_END` |
| `PHASE_GROUP_MIRACLE` | 全体奇跡の発動時、追加で「精霊系」カード等を選択する全体奇跡攻撃フェイズ。 | 手番プレイヤー (Active) | 相手対象（ターゲットは相手全体 `OPP` のみ）決定で `PHASE_MIRACLE_DEFENSE` |
| `PHASE_MIRACLE_DEFENSE` | 相手から受けた奇跡に対して、反射や阻止アクションを選択するフェイズ（物理/属性防御と異なり、奇跡防具の防御力数値による減算計算は行われません）。 | 防御プレイヤー (Defender) | `PHASE_END` |
| `PHASE_SELL_SELECT` | 「売る」カード使用後、自分の手札から売り出したいアイテムカードを選択するフェイズ。 | 手番プレイヤー (Active) | `PHASE_MAIN_TARGET_SELECT` |
| `PHASE_SELL_SELECT_MIRROR` | 相手にアイテムを売りつける際、買い手側が「スーパーミラー」で反射するか「受諾(CONFIRM)」するかを選択するフェイズ。 | 買い手プレイヤー (Defender) | `PHASE_END` (受諾時) または 反射され入れ替わった `PHASE_SELL_SELECT_MIRROR` (反射時) |
| `PHASE_BUY` | 相手の手札から提示されたカードをお金を払って購入するか（YES/NO）を選択するフェイズ。 | 買い手プレイヤー (Active) | `PHASE_END` |
| `PHASE_BUY_SELECT_MIRROR` | 「買う」カード使用時、売り手側が「スーパーミラー」で反射するか「受諾(CONFIRM)」するかを選択するフェイズ。 | 売り手プレイヤー (Defender) | `PHASE_BUY` (受諾時)、反射され入れ替わった `PHASE_BUY_SELECT_MIRROR` (反射時)、または `PHASE_END` (取引失敗時) |
| `PHASE_SUNDRY_SELECT_MIRROR` | 相手に「雑貨」カードを使用する際、対象側が「スーパーミラー」で反射するか「受諾(CONFIRM)」するかを選択するフェイズ。 | 対象プレイヤー (Defender) | `PHASE_END` (受諾時) または 反射され入れ替わった `PHASE_SUNDRY_SELECT_MIRROR` (反射時) |
| `PHASE_EXCHANGE_HP` / `PHASE_EXCHANGE_MP` | 「両替」カード使用時、HPまたはMPに充当する数値を決定・入力するフェイズ。 | 手番プレイヤー (Active) | `PHASE_END` |
| `PHASE_DISCARD` | 「捨てる」アクションを選択した際、捨てる手札を選択するフェイズ。 | 手番プレイヤー (Active) | `PHASE_END` |
| `PHASE_END` | ターン終了時のクリーンアップ処理（風邪・熱・地獄のダメージ適用など）を行うフェイズ。 | 自動処理 (Auto-advanced) | 次のプレイヤーの `PHASE_MAIN` |

## 2. 自分対象（自分自身をターゲットにした場合）の特殊挙動

ゴッドフィールドの原作仕様に則り、自分自身を対象にしたアクション（自傷、自売り、自己買いなど）は、防御やカウンター、合意形成のための割り込みフェイズをスキップして即時に効果が解決されます。

### A. 「売る」で自分を対象にした場合
- **遷移**: 「売る」使用 -> 売りたい手札を選択 -> **対象に「自分」を選択**。
- **解決ルール**:
  - 買い手からのミラー確認フェイズ（`PHASE_SELL_SELECT_MIRROR`）は**完全にスキップ**されます。
  - 対象に「自分」を選択したステップ内で、即座に売買決済が処理されます。
  - **支払いの解決**: プレイヤー自身が、そのカードの売値（Price）分の金額を「所持金 -> MP -> 残りHP」の優先順位で支払います（HPから支払った分はダメージになります）。
  - **代金の受け取り**: プレイヤー自身に売値分のお金（Money）が支払われます（上限99）。
  - **カードの移動**: 売却されたカードは自分の手札から一度消去された後、自分の空きスロットに戻されます（空きがない場合はランダムに1枚上書きされます）。
  - 処理終了後、即座に `PHASE_END`（ターン終了）に遷移します。

### B. 「買う」で自分を対象にした場合
- **遷移**: 「買う」使用 -> **対象に「自分」を選択**。
- **解決ルール**:
  - 自分自身からカードを購入する取引そのものは発生しません。
  - 使用者の手札からランダムに1枚が選択され、相手プレイヤーに対して公開状態（`is_known_to_opp = true`）になります。
  - お金やMPの支払いや、カードの移動処理などは一切発生しません。
  - 処理終了後、即座に `PHASE_END`（ターン終了）に遷移します。

### C. 「雑貨」で自分を対象にした場合
- **遷移**: 雑貨カード使用 -> **対象に「自分」を選択**。
- **解決ルール**:
  - 相手への使用時に発生するミラー反射等の確認フェイズは**スキップ**されます。
  - 雑貨カードの効果（ステータス回復、病気治療など）が即座に使用者自身に適用されます。
  - 処理終了後、即座に `PHASE_END`（ターン終了）に遷移します。

### D. 「攻撃 / 奇跡」で自分を対象にした場合（自傷）
- **遷移**: 攻撃/奇跡の発動 -> **対象に「自分」を選択**。
- **解決ルール**:
  - 相手ターン時の防御リアクションフェイズ（`PHASE_DEFENSE`, `PHASE_MIRACLE_DEFENSE`）は**スキップ**されます。
  - 攻撃力や奇跡の効果（ダメージやステータス異常）が即座に使用者自身に適用されます。
  - 処理終了後、即座に `PHASE_END`（ターン終了）に遷移します。

## 3. 「売る」に対するスーパーミラー反射時の特殊挙動

取引（売買）フェイズ特有の複雑な挙動として、相手から提示された「売る」のアクションをスーパーミラーで反射した場合のルールを記述します。

- **遷移**: 
  1. プレイヤーAが手札カードXをプレイヤーBに売ろうとする (`PHASE_SELL_SELECT` -> `PHASE_MAIN_TARGET_SELECT`にて対象にBを選択)
  2. Bは `PHASE_SELL_SELECT_MIRROR` において「スーパーミラー」を使用
  3. **反射の発生**: ロール（売り手/買い手）がスワップされ、アクターがプレイヤーA（元の売り手）に交代。フェイズは `PHASE_SELL_SELECT_MIRROR` のまま維持されます。
- **解決ルール**:
  - **対象カードの固定**: 反射された場合であっても、売買される対象カードは「元の売り手Aが売ろうとしていたカードX」で**固定**されます。反射側（B）が新たに自分の手札からカードを選択し直す必要はありません。
  - **手札制限の免除**: 反射側（B）はカードを売りつける立場（売り手）になるため、自分の手札が一杯であっても何ら問題なく反射が機能します。
  - **再反射**: アクターとなったAは、さらにスーパーミラーを出して反射し返すことができます。
  - **決済**: 最終的にミラーを使用せずに受諾（`ACTION_CONFIRM`）された場合、その時点での「売り手」が代金を受け取り、「買い手」が代金を支払いカードXを引き取ります。

---

## 4. 「買う」に対するスーパーミラー反射時の特殊挙動

相手から提示された「買う」のアクションをスーパーミラーで反射した場合のルールを記述します。

- **遷移**: 
  1. プレイヤーAがプレイヤーBに対して「買う」を使用する（`PHASE_MAIN_TARGET_SELECT` にて対象にBを選択）。
  2. Bは `PHASE_BUY_SELECT_MIRROR` において「スーパーミラー」を使用。
  3. **反射の発生**: ロール（買い手/売り手）がスワップされ（Bが買い手、Aが売り手となる）、アクターがプレイヤーA（元の買い手）に交代。フェイズは `PHASE_BUY_SELECT_MIRROR` のまま維持されます。
- **解決ルール**:
  - **再反射**: アクターとなったAは、さらにスーパーミラーを出して反射し返すことができます（その場合、再度ロールがスワップされてBに交代します）。
  - **合意・決済**: 最終的にミラーを使用せずに受諾（`ACTION_CONFIRM`）された場合、その時点での「買い手（アクターの相手側）」がカードを購入する権利を得て、フェイズが `PHASE_BUY` に移行します。
    - 受諾したプレイヤー（売り手）の手札からランダムに1枚のカードが公開され提示されます。この際、すでに使用中（`is_used = true`）のカードやコマンドカードは選択対象から除外されます。
    - 買い手は、提示されたカードに対して「購入する（YES）」か「購入しない（NO）」を選択し、取引が決済されます。

---

## 5. 「雑貨」に対するスーパーミラー反射時の特殊挙動

相手から使用された「雑貨（天国草、カラス、悪魔など）」のアクションをスーパーミラーで反射した場合のルールを記述します。

- **遷移**: 
  1. プレイヤーAがプレイヤーBに対して雑貨カードを使用する（`PHASE_MAIN_TARGET_SELECT` にて対象にBを選択）。
  2. Bは `PHASE_SUNDRY_SELECT_MIRROR` において「スーパーミラー」を使用。
  3. **反射の発生**: ロール（攻撃側/防御側）がスワップされ（Bが攻撃側、Aが防御側となり、BがAに向けて雑貨を使う形になる）、アクターがプレイヤーAに交代。フェイズは `PHASE_SUNDRY_SELECT_MIRROR` のまま維持されます。
- **解決ルール**:
  - **再反射**: アクターとなったAは、さらにスーパーミラーを出して反射し返すことができます（その場合、再度ロールがスワップされてBに交代します）。
  - **合意・決済**: 最終的にミラーを使用せずに受諾（`ACTION_CONFIRM`）された場合、その時点での「防御側（アクター）」に対して、元の雑貨カードの効果が適用されます。
    - 適用後、両者の仮置きカードはリセットされ、`PHASE_END` に遷移してターンが終了します。
