# ゴッドフィールド ルール定義書

本ドキュメントは、強化学習環境およびシミュレータの実装基準となるゴッドフィールドの基本ルールと挙動を定義するものです。

## 1. 勝利条件と基本システム
* **プレイヤー**: 1対1 (1v1)
* **勝利条件**: 相手のHP（体力）を0にする。同時にHPが0になった場合は引き分け。
* **ターン制**: 先攻・後攻が交互に行動を行う。ただし、相手の攻撃行動に対して防御カードを使用したり、反撃することができる。
攻撃側が反撃に対してさらに防御したりと、ターン制ではあるものの、相手のターン中にも行動のリレーがいくつか発生する。
* **カードプール**: 各プレイヤーは共通の確率的なカードプールから i.i.d でカードを9枚引き、対戦を始める。1枚カードを使うと1枚ドローできる。

## 2. プレイヤーステータス
各プレイヤーは以下の3値のステータスを持つ。ステータスは公開情報である。

* **HP (体力)**: 初期値 40。0以下で敗北。上限は99。
* **MP (魔力)**: 初期値 10。奇跡や一部の神器を使用する際に消費する。特定アイテムで回復。上限は99。
* **円 (お金)**: 初期値 20。「買う」行動に消費する。「売る」で増加する。上限は99。

### 2.1 病
特定の武器の攻撃を受ける、特定の防具を使う、特定の奇跡を受ける、特定のアイテムを使用することで、プレイヤーは病になる。
病は公開情報である。各病は独立しておらず、どれか1つのみかかる。

病の種類 (程度順)：
- 風邪 (Cold)：毎ターン終了時に1ダメージを受ける
- 熱病 (Fever): 毎ターン終了時に2ダメージを受ける
- 地獄病 (Hell): 毎ターン終了時に5ダメージを受ける
- 天国病 (Heaven): 毎ターン終了時に5ダメージ回復する

病は毎ターン5%の確率でターン終了時に自然に悪化する。
既にかかっている病より低級の病を重ねると1段階悪化する。上級の病を重ねると、上級の病になる。
天国病が悪化するとHPが0になる。

例: 
- 熱病のときに風邪を受けると地獄病になる。
- 天国病のときに風邪を受けると発作で死ぬ。
- 風邪のときに地獄病を受けると地獄病になる。

### 2.2 状態異常
プレイヤーは状態異常にかかる。状態異常は4種類。
特定のアイテムや奇跡で回復できる。
状態異常は公開情報である。また、各状態異常は独立してかかる。


* **霧 (Fog)**:
  * 相手プレイヤーの情報（HP/MP/お金/展開済みの奇跡など）が見えなくなる。
  * AIの観測（Observation）において、自分が霧状態の場合、相手の公開ステータスは「0（または特定値）」でマスクされる。
* **閃光 (Flash)**
  * 防御カードを同時に最大1つしか使えなくなる。
* **暗雲 (Dark Cloud)**
  * 確率で命中する攻撃を必ず被弾する。
* **夢 (Dream)**:
  * 自分の手札が幻覚として別のカードに見えてしまう。
  * 50%の確率で、カードが属する「グループ」内の別のランダムなカードに偽装されてAIの観測値に乗る（真のゲームステートは元のまま）。これによりPOMDP（部分観測マルコフ決定過程）となる。

### 2.3 守護神
プレイヤーは最大1体の守護神を付けることができる。守護神は公開情報である。

守護神は10体存在し、守護神を付けるときに等確率で選ばれる。
- 火星神
- 水星神
- 木星神
- 土星神
- 天王神
- 冥王神
- 海王神
- 金星神
- 地球神
- 月神

守護神の行動ルール:
- 守護神は敵のターンの後に25%の確率で行動する。
- 守護神はダメージを受けると10%の確率で去る。
- 地球神、月神以外の守護神は決まった5種類の行動の中から確率的に決まった行動をとる。
- 地球神は新しくカードをドローし、そのカードの種類に応じて行動する。
- 月神は28種類の奇跡の中からランダムに奇跡を使用する。

## 3. カードの種類
* **取引**: 売る、買う、両替、捨てる。の4行動。
* **武器**: 相手にダメージを与える。
  * **プラス武器**: 武器は本来1枚しか使えないが、プラス武器は追加で使用でき、攻撃力を加算する。
  * **命中率**: 基本的に100%だが、いくつかの武器は命中率が存在する。
  * **防具兼用武器**: いくつかの武器は防具としても使える。
  * **反射武器**: 特定の武器は相手の無属性攻撃を50%で跳ね返したり、100%で反射したりする。
* **防具**: 相手からの攻撃（ダメージ）を軽減または無効化・反射する。
  * **合成**: 相手の攻撃に合わせて複数の防具を同時に展開して防御値を合算可能。
  * **指輪**: 指輪と呼ばれる防具は、それを使った防御のときにダメージを受けた場合に効果を発揮する。
  * **虹のカーテン**: 虹のカーテンという防具は相手の属性攻撃を無属性にする。
  * **スーパーミラー**: あらゆるタイミングで使用可能な防具で、任意の効果を相手に反射する。
* **雑貨**: 様々な効果を発揮するアイテム
  * **HP/MP回復**: HPやMPを一定量回復する
  * **貝殻**: 状態異常を回復する。霧・閃光・風邪・熱病だけを払うスマイルの貝殻と、全ての災いを払うハートの貝殻がある。
  * **その他**: 守護神の召喚や相手の奇跡の破壊、超常現象を起こす、死ぬとき持っていれば蘇生、など様々な効果の雑貨がある。
* **奇跡**: MPを消費して強力な効果（攻撃、回復、状態異常付与など）を発動する。
  * **奇跡の防御**: 相手から奇跡攻撃を受けた場合、通常の防具の防御力数値によるダメージ減算ではなく、奇跡を無効化（阻止）したり跳ね返したり（反射）する専用の奇跡防具（霧氷の鎧など）で対抗します（物理防御のように防御力による減算計算は行われません）。
  * **使用済みと未使用の区別**: 手札にある奇跡（未使用・相手から見えない）を使用すると、盤面に「展開（使用済み）」される。展開された奇跡は相手にも公開され、手札枠を圧迫せず毎ターンMPさえあれば何度でも使用可能になる。
  * **使用済みは固定される**: 一度起こした奇跡は売る、買う、夜空のホウキの対象とならず、女神の石鹸か手札が溢れてランダム破棄される以外で無くならない。

プレイヤーが持てる手札の最大数は18枚である。これは使用済みの奇跡も含まれる。
これ以上手札が増えた場合、既存の手札がランダムに1枚捨てられて置き換えられる。


### 3.1 取引
前提として、すべてのカードは決まった値段がついている (公開情報)。


- **捨てる**
  - 常時行える
  - 武器、太陽のお守り、あぶないウスは捨てられない
  - 使用済みの奇跡も捨てることができる

- **両替カード**
  - HP/MP/お金 を任意に相互変換する
  - 元と合計が同じかつ、それぞれが99を超えなければよい
  - HPを0にすると死ぬ

- **買うカード**
  - 相手の手札からランダムに1枚見ることができ、自分の所持するお金がそのカードの値段より多いなら、買うか買わないかを選択できる。
  - 買った場合、お金を相手に払い、カードを手札に入れる。
  - 手札が18枚のときに買うと、ランダムに1枚が破棄され置き換えられる。
  - 相手は買うというアクションに対してスーパーミラー以外で拒否できない
  - スーパーミラーを使うと相手が逆に自分に買うをする

- **売るカード**
  - 自分のカードを1枚選び、相手に強制的に売りつける
  - 相手のお金が足りない場合MPで、MPも足りない場合HPで払わせる
  - 相手はスーパーミラー以外で拒否できない
  - 売られた側がスーパーミラーを使うと、そのアイテムを相手が自分に売ったことになる

なお、売る、買うは自分に対しても使える。
自分に対して買うと、相手にカードを1枚見られるが、何も起こらない。
自分に対して売ると、相手に売ったカードを見られるのと、お金が足りないとMPやHPがお金になってしまう (最悪死ぬ)。

### 3.2 属性
武器や奇跡による攻撃、防具には属性が存在する。

- 無属性 (Non-element)\
  無属性の攻撃は任意の属性で防御できる。
- 火属性 (Fire)\
  火属性の攻撃は水属性で防御できる。
- 水属性 (Water)\
  水属性の攻撃は火属性で防御できる。
- 木属性 (Wood)\
  木属性の攻撃は土属性で防御できる。
- 土属性 (Stone)\
  土属性の攻撃は木属性で防御できる。
- 光属性 (Light)\
  光属性の攻撃はどの属性でも防御できない。
- 闇属性 (Darkness)\
  闇属性の攻撃はどの属性でも防御できる。ただし、ダメージを受けた場合はHPが0になる。

異なる属性を同時に重ねると、無属性になる。
光属性は火、水、木、土属性の代わりになる。

## その他
### 超常現象
運命のひも というカードを使用すると、以下の超常現象の中からランダムに1つが選ばれる。

- 夕焼け:\
  全員に熱病。これは病を上書きする。
- 濃霧:\
  全員に霧
- きのこ大発生:\
  全員がランダムに3ターン行動する
- 竜巻:\
  全員のHPが1になる
- 巨大なタライ:\
  誰かに光属性攻50
- ブラックホール:\
  闇属性75%攻30
- 暖流:\
  自身のHP+50
- 金山:\
  全員の所持金の合計が誰かに集まる
- 磁器嵐:\
  プレイヤーのカードが無作為に入れ替わる
- 日食:\
  すべてのプレイヤーに守護神がつく。上書きされる。

ブラックホールや巨大なタライは自分が使用した判定になるので、スーパーミラーで跳ね返される。
