# ゴッドフィールド ルール定義書

本ドキュメントは、強化学習環境およびシミュレータの実装基準となるゴッドフィールドの基本ルールと挙動を定義するものです。

## 1. 勝利条件と基本システム
* **プレイヤー**: 1対1 (1v1)
* **勝利条件**: 相手のHP（体力）を0にする、または特殊勝利（昇天など）を満たす。同時にHPが0になった場合は引き分け。
* **ターン制**: 先行・後攻が交互に行動を行う。

## 2. プレイヤーステータス
各プレイヤーは以下のステータスを持つ。
* **HP (体力)**: 初期値 40。0以下で敗北。
* **MP (魔力)**: 初期値 10。奇跡や一部の神器を使用する際に消費する。ターン経過や特定アイテムで回復。上限は原則なし。
* **円 (お金)**: 初期値 0。特定のカードを購入したり、「買う」行動に消費する。

## 3. カードの種類と合成（コンボ）
* **武器**: 相手にダメージを与える。
  * **合成**: 複数の武器を同時に使用してダメージを合算することが可能（例外あり）。
* **防具**: 相手からの攻撃（ダメージ）を軽減または無効化・反射する。
  * **合成**: 相手の攻撃に合わせて複数の防具を同時に展開して防御値を合算可能。
* **奇跡**: MPを消費して強力な効果（攻撃、回復、状態異常付与など）を発動する。
  * **使用済みと未使用の区別**: 手札にある奇跡（未使用・相手から見えない）を使用すると、盤面に「展開（使用済み）」される。展開された奇跡は相手にも公開され、手札枠を圧迫せず毎ターンMPさえあれば何度でも使用可能になる。
* **神器 (アイテム/雑貨)**: 使い捨ての特殊効果カード。

## 4. 状態異常
プレイヤーは様々な状態異常にかかる。代表的なものは以下の通り。
* **霧 (Fog)**:
  * かかったプレイヤー自身の情報（HP/MP/お金/展開済みの奇跡など）が相手から見えなくなる。
  * AIの観測（Observation）において、相手が霧状態の場合、相手の公開ステータスは「0（または特定値）」でマスクされる。
* **夢 (Dream)**:
  * 自分の手札が幻覚として別のカードに見えてしまう。
  * 50%の確率で、カードが属する「グループ」内の別のランダムなカードに偽装されてAIの観測値に乗る（真のゲームステートは元のまま）。これによりPOMDP（部分観測マルコフ決定過程）となる。
* **その他の状態**: 風邪（毎ターン微ダメージ）、地獄病（回復無効）など（実装を進めながら随時追加）。

## 5. 守護神
プレイヤーには守護神が憑くことがある。守護神は公開情報であり、プレイヤーにパッシブなバフ（例: 常時防御力+）や、特定の攻撃からの完全防御などの恩恵をもたらす。

## 6. アクション（行動空間）の定義
AIが取り得る行動は、固定長ベクトル（例: `[カードID1, カードID2, ターゲット, ...]`）として表現する。
1. **攻撃/使用**: 1枚以上のカードを選択して使用。
2. **防御**: 相手の攻撃に対し、1枚以上の防御カードを選択して使用。
3. **買う/売る**: お金を使って行動する（ゲームの特殊ルール）。
4. **パス**: 何もせずにターンを終了する。無効な組み合わせを選択した場合も強制的にパス（またはペナルティ）扱いとなる。
