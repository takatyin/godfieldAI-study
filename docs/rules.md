# ゴッドフィールド ルール定義書

本ドキュメントは、強化学習環境およびシミュレータの実装基準となるゴッドフィールドの基本ルールと挙動を定義するものです。

## 1. 勝利条件と基本システム
* **プレイヤー**: 1対1 (1v1)
* **勝利条件**: 相手のHP（体力）を0にする。同時にHPが0になった場合は引き分け。
* **ターン制**: 先攻・後攻が交互に行動を行う。ただし、相手の攻撃行動に対して防御カードを使用したり、反撃することができる。
攻撃側が反撃に対してさらに防御したりと、ターン制ではあるものの、相手のターン中にも行動のリレーがいくつか発生する。
* **カードプール**: 各プレイヤーは共通の確率的なカードプールから i.i.d でカードを9枚引き、対戦を始める。1枚カードを使うと1枚ドローできる。

## 2. プレイヤーステータス
各プレイヤーは以下の3値のステータスを持つ。ステータスは公開情報である。

* **HP (体力)**: 初期値 40。0以下で敗北。上限は99。
* **MP (魔力)**: 初期値 10。奇跡や一部の神器を使用する際に消費する。特定アイテムで回復。上限は99。
* **円 (お金)**: 初期値 20。「買う」行動に消費する。「売る」で増加する。上限は99。

### 2.1 病
特定の武器の攻撃を受ける、特定の防具を使う、特定の奇跡を受ける、特定のアイテムを使用することで、プレイヤーは病になる。
病は公開情報である。各病は独立しておらず、どれか1つのみかかる。

病の種類 (程度順)：
- 風邪 (Cold)：毎ターン終了時に1ダメージを受ける
- 熱病 (Fever): 毎ターン終了時に2ダメージを受ける
- 地獄病 (Hell): 毎ターン終了時に5ダメージを受ける
- 天国病 (Heaven): 毎ターン終了時に5ダメージ回復する

病は毎ターン5%の確率でターン終了時に自然に悪化する。
既にかかっている病より低級の病を重ねると1段階悪化する。上級の病を重ねると、上級の病になる。
天国病が悪化するとHPが0になる。

例: 
- 熱病のときに風邪を受けると地獄病になる。
- 天国病のときに風邪を受けると発作で死ぬ。
- 風邪のときに地獄病を受けると地獄病になる。

### 2.2 状態異常
プレイヤーは状態異常にかかる。状態異常は4種類。
特定のアイテムや奇跡で回復できる。
状態異常は公開情報である。また、各状態異常は独立してかかる。


* **霧 (Fog)**:
  * 相手プレイヤーの情報（HP/MP/お金/展開済みの奇跡など）が見えなくなる。
  * AIの観測（Observation）において、自分が霧状態の場合、相手の公開ステータスは「0（または特定値）」でマスクされる。
* **閃光 (Flash)**
  * 防御カードを同時に最大1つしか使えなくなる。
* **暗雲 (Dark Cloud)**
  * 確率で命中する攻撃を必ず被弾する。
* **夢 (Dream)**:
  * 自分の手札が幻覚として別のカードに見えてしまう。
  * 50%の確率で、カードが属する「グループ」内の別のランダムなカードに偽装されてAIの観測値に乗る（真のゲームステートは元のまま）。これによりPOMDP（部分観測マルコフ決定過程）となる。

### 2.3 守護神
プレイヤーは最大1体の守護神を付けることができる。守護神は公開情報である。
守護神は10体存在し、召喚（「守護封印のつぼ」や超常現象「日食」など）されたときに等確率で選ばれる。

**守護神の基本ルール**:
- **行動確率**: 敵のターンが終了した後に **25% の確率で行動**する（手番が終了したプレイヤーの対戦相手に憑いている守護神が行動する）。
- **退散確率**: 守護神がついているプレイヤーが **ダメージを受けてHPが減少した際、10% の確率で去る（退散する）**。
  - *対象となるダメージ*: 物理攻撃や奇跡攻撃による戦闘ダメージ、およびターン終了時の病（風邪、熱病、地獄病）によるダメージ。
  - *対象外*: 天国病による回復、「売る」の支払いによるHP減少、「両替」によるHP消費（これらは「ダメージ」とはみなされません）。
- **行動内容**: 地球神、月神以外の守護神は、決まった5種類の行動の中から確率（重み: 30/25/20/15/10%）に基づいて行動する。地球神は山札からドローしてそのカードに応じて行動し、月神はランダムな奇跡を使用する。

## 3. カードの種類
* **取引**: 売る、買う、両替、捨てる。の4行動。
* **武器**: 相手にダメージを与える。
  * **プラス武器**: 武器は本来1枚しか使えないが、プラス武器は追加で使用でき、攻撃力を加算する。
  * **命中率**: 基本的に100%だが、いくつかの武器は命中率が存在する。
  * **防具兼用武器**: いくつかの武器は防具としても使える。
  * **反射武器**: 特定の武器は相手の無属性攻撃を50%で跳ね返したり、100%で反射したりする。
* **防具**: 相手からの攻撃（ダメージ）を軽減または無効化・反射する。
  * **合成**: 相手の攻撃に合わせて複数の防具を同時に展開して防御値を合算可能。
  * **指輪**: 指輪と呼ばれる防具は、それを使った防御のときにダメージを受けた場合に効果を発揮する。
  * **虹のカーテン**: 虹のカーテンという防具は相手の属性攻撃を無属性にする。
  * **スーパーミラー**: あらゆるタイミングで使用可能な防具で、任意の効果を相手に反射する。
* **雑貨**: 様々な効果を発揮するアイテム
  * **HP/MP回復**: HPやMPを一定量回復する
  * **貝殻**: 状態異常を回復する。霧・閃光・風邪・熱病だけを払うスマイルの貝殻と、全ての災いを払うハートの貝殻がある。
  * **その他**: 守護神の召喚や相手の奇跡の破壊、超常現象を起こす、死ぬとき持っていれば蘇生、など様々な効果の雑貨がある。
* **奇跡**: MPを消費して強力な効果（攻撃、回復、状態異常付与など）を発動する。
  * **奇跡の防御**: 相手から奇跡攻撃を受けた場合、通常の防具の防御力数値によるダメージ減算ではなく、奇跡を無効化（阻止）したり跳ね返したり（反射）する専用の奇跡防具（エンゼルアーマーなど）で対抗します（物理防御のように防御力による減算計算は行われません）。
  * **使用済みと未使用の区別**: 手札にある奇跡（未使用・相手から見えない）を使用すると、盤面に「展開（使用済み）」される。展開された奇跡は相手にも公開され、手札枠を圧迫せず毎ターンMPさえあれば何度でも使用可能になる。
  * **展開制限とFIFO制御**: 展開できる奇跡の数は**最大6個**までである。すでに6個展開されている状態で新たに7個目の奇跡を展開した場合、**最も古く展開された（最初に展開された）奇跡が自動的に未展開化され消滅（手札枠から CARD_EMPTY になる）**する FIFO (First-In, First-Out) 制御が行われる。
  * **使用済みは固定される**: 一度起こした奇跡は売る、買う、夜空のホウキの対象とならず、上記展開制限によるFIFO消滅、女神の石鹸による破壊、または手札全体の最大数超過によるランダム破棄以外で無くならない。

プレイヤーが持てる手札の最大数は18枚である。これは使用済みの奇跡も含まれる。
これ以上手札が増えた場合、既存の手札がランダムに1枚捨てられて置き換えられる。


### 3.1 取引
前提として、すべてのカードは決まった値段がついている (公開情報)。


- **捨てる**
  - 常時行える
  - 武器、太陽のお守り、あぶないウスは捨てられない
  - 使用済みの奇跡も捨てることができる

- **両替カード**
  - HP/MP/お金 を任意に相互変換する
  - 元と合計が同じかつ、それぞれが99を超えなければよい
  - HPを0にすると死ぬ

- **買うカード**
  - 相手の手札からランダムに1枚見ることができ、自分の所持するお金がそのカードの値段より多いなら、買うか買わないかを選択できる。
  - 買った場合、お金を相手に払い、カードを手札に入れる。
  - 手札が18枚のときに買うと、ランダムに1枚が破棄され置き換えられる。
  - 相手は買うというアクションに対してスーパーミラー以外で拒否できない
  - スーパーミラーを使うと相手が逆に自分に買うをする

- **売るカード**
  - 自分のカードを1枚選び、相手に強制的に売りつける
  - 相手のお金が足りない場合MPで、MPも足りない場合HPで払わせる
  - 相手はスーパーミラー以外で拒否できない
  - 売られた側がスーパーミラーを使うと、そのアイテムを相手が自分に売ったことになる

なお、売る、買うは自分に対しても使える。
自分に対して買うと、相手にカードを1枚見られるが、何も起こらない。
自分に対して売ると、相手に売ったカードを見られるのと、お金が足りないとMPやHPがお金になってしまう (最悪死ぬ)。

### 3.2 属性
武器や奇跡による攻撃、防具には属性が存在する。

- 無属性 (Non-element)\
  無属性の攻撃は任意の属性で防御できる。
- 火属性 (Fire)\
  火属性の攻撃は水 or 光属性の防具で防御できる。
- 水属性 (Water)\
  水属性の攻撃は火 or 光属性の防具で防御できる。
- 木属性 (Wood)\
  木属性の攻撃は土 or 光属性の防具で防御できる。
- 土属性 (Stone)\
  土属性の攻撃は木 or 光属性の防具で防御できる。
- 光属性 (Light)\
  光属性の攻撃はどの属性でも防御できない。
- 闇属性 (Darkness)\
  闇属性の攻撃はどの属性でも防御できる。ただし、ダメージを受けた場合はHPが0になる。

違う属性の神器を複数使用すると、無属性になる。
ただし、光属性のみ例外で、火・水・木・土属性の神器と共用すると、その属性に変化する（例: 光＋火＝火）。
また、「○属性に染める」という効果を持つ武器（火のワンド、水のワンド等）は、無条件で攻撃をその属性にする。

### 3.3 攻撃の4パターンとフェイズ遷移（蜃気楼・全体攻撃）
攻撃カードの使用時、ベースとなるカードと追加カードの有無によって、以下の4つの攻撃フェイズに分岐します。

1. **単体武器攻撃** (`PHASE_ATTACK_PLUS`)
   * メインフェイズで単体武器を使用した場合に移行。
   * プラス武器や攻撃奇跡を重ねがけ可能。
   * 防御側は「物理/属性防御（`PHASE_DEFENSE`）」を行う。自傷（自分対象）も可能。
   * 特殊カード「＜蜃気楼＞」を重ねた場合、即座に **全体武器攻撃** (`PHASE_GROUP_WEAPON`) へ移行する。
2. **全体武器攻撃** (`PHASE_GROUP_WEAPON`)
   * メインフェイズで全体攻撃武器（火の粉袋など）を使用、または単体武器に「＜蜃気楼＞」を重ねた場合に移行。
   * 他の追加カード（プラス武器や一般攻撃奇跡など）は重ねがけ不可。ただし、「精霊のぬいぐるみ」等のMP相殺カード、および「＜蜃気楼＞」のさらなる重複は可能。
   * **ターゲット制限**: ターゲットは相手全体（`OPP`）のみとなり、自傷（自分対象）は選択できない。
   * 防御側は「物理/属性防御（`PHASE_DEFENSE`）」を行う。
   * **複数蜃気楼の処理**: 単体武器に対して $n$ 枚の「＜蜃気楼＞」を重ねて使用すると、全体攻撃扱いで同じ攻撃を $n$ 回繰り返す（防御側も $n$ 回防御判定を行う）。
3. **単体奇跡攻撃** (`PHASE_MIRACLE_PLUS`)
   * メインフェイズで単体奇跡（火の玉など）を使用した場合に移行。
   * MPを相殺するための「精霊系」カードのみ重ねがけ可能（1枚目に火の玉や流星を使用した場合、それらは単体攻撃奇跡として扱われ、他のプラス奇跡や武器を追加することはできません）。
   * **MP相殺ルール**: 「精霊系」カードは、**その直前（左隣）に置かれた奇跡カード1枚のみ**の消費MPを `0` にします（例: `木の棒` + `＜火の玉＞` + `＜蜃気楼＞` + `精霊のぬいぐるみ` の場合、直前にある `＜蜃気楼＞` の消費MPのみが `0` になり、手前の `＜火の玉＞` のMPは通常通り消費され合計 2 MPとなります）。
   * 防御側は「奇跡防御（`PHASE_MIRACLE_DEFENSE`）」を行う。自傷（自分対象）も可能。
4. **全体奇跡攻撃** (`PHASE_GROUP_MIRACLE`)
   * メインフェイズで全体奇跡（＜煙＞など）を使用した場合に移行。
   * MPを相殺するための「精霊系」カードのみ重ねがけ可能。
   * **MP相殺ルール**: 単体奇跡と同様に、直前に置かれた全体奇跡の消費MPのみを `0` にします。
   * **ターゲット制限**: ターゲットは相手全体（`OPP`）のみとなり、自傷（自分対象）は選択できない。
   * 防御側は「奇跡防御（`PHASE_MIRACLE_DEFENSE`）」を行う。

### 3.4 防御フェイズにおけるリアクション（bounce/reflect/block）と虹のカーテンの連携

防御フェイズ（`PHASE_DEFENSE` および `PHASE_MIRACLE_DEFENSE`）において、相手の攻撃を無効化・反射するためのリアクションカードと、一般の防具（木盾など）の重ねがけには以下の制約と解決フローが存在します。

#### 1. 排他ルールと重ねがけ制約
* **リアクションと防具の排他**:
  * 阻止（block）、弾く（bounce）、反射（reflect）を行うリアクションカード（スーパーミラー、壁、乱気流、各種奇跡防御装備）は、一般防具（木盾や革の服など）と一緒に重ねがけすることはできません。
  * リアクションカードは常に**防御の最初（1枚目）**に選択して出す必要があります。一度一般防具を置いた場合、以降はリアクションカードを重ねることはできなくなります。
  * 例外として、リアクションカードが「奇跡」（`＜乱気流＞`等）である場合のみ、そのMP消費を 0 にするために「精霊系カード」を追加で重ねることが許可されます。

* **虹のカーテン (Rainbow Curtain) の配置制約**:
  * `虹のカーテン` は**防御の最初（1枚目）にしか出せません**（`num_staged_cards == 0` の時のみ選択可能）。
  * 虹のカーテンは「防具を使用した」とは判定されない（属性を消すだけで防御力0）ため、例外的にその後にリアクションカードを置くことができます。

* **物理防御フェイズ（`PHASE_DEFENSE`）での虹のカーテン連携**:
  * 属性武器攻撃に対して、最初に `虹のカーテン` を置くことで攻撃を無属性化できます。
  * この場合、例外として2枚目のカードとして無属性物理リアクションカード（`反射剣` や `＜壁＞`、`乱弾武剣`）を置くことが許可されます。
    * 例: `虹のカーテン` ＋ `壁` ＋ `精霊のぬいぐるみ` （合法手）
    * 例: `虹のカーテン` ＋ `反射剣` （合法手）

* **奇跡防御フェイズ（`PHASE_MIRACLE_DEFENSE`）での虹のカーテン連携**:
  * 奇跡に対しては、元々の属性に関わらず常に阻止・弾く・反射（`＜乱気流＞` 等）が可能です。
  * したがって、奇跡防御で `虹のカーテン` の後にリアクションカード（`乱気流` など）を重ねる必要はなく、これは**非合法**となります（`虹のカーテン` ＋ `乱気流` は不可）。
  * ただし、属性奇跡攻撃に対して `虹のカーテン` を置いて無属性化し、その後に `無属性一般防具（木盾など）複数` を重ねて耐えるルートは**合法**です。
    * 例: `虹のカーテン` ＋ `木盾` ＋ `革の服` （合法手）

#### 2. 各リアクションカードの有効制約
* **`反射剣` / `＜壁＞` / `乱弾武剣`**:
  * **無属性の物理武器攻撃のみ**に対して有効です。攻撃属性が有属性である場合、単体では使用できません（`虹のカーテン` で中和する必要があります）。
* **`＜乱気流＞`**:
  * **すべての奇跡攻撃**に対して常に有効です。

#### 3. ダメージ奇跡と状態異常奇跡（攻撃力 0）の防御制限
* **攻撃力 > 0 の奇跡攻撃（例：＜岩＞、＜炎＞など）**:
  * 属性相性が一致する一般防具（例：`魔神の木馬` などの対抗属性防具）や、`虹のカーテン` を最初に出した後の一般防具による防御が可能です。
* **攻撃力 = 0 の状態異常奇跡（例：＜霧＞、＜夢＞、＜風邪＞など）**:
  * 一般防具および一般防具を重ねる前提となる `虹のカーテン` は**一切使用できません（非合法手となります）**。
  * これらはダメージを伴わないため防御力による減算が不可能であり、防ぐには奇跡防御専用リアクションカード（`＜乱気流＞`等）、専用の奇跡防具（`月光の盾`、`月光のかぶと`、`月光のよろい`、`エンゼルアーマー`等）、または `スーパーミラー` のみで防御が可能です。

#### 4. 反射・弾きの解決と攻守交代（入れ替わり）
* 防御側が反射（100%成功）または弾き成功（50%の確率で成功）した場合：
  * 攻撃が元の攻撃者（A）へと跳ね返り、**Aが防御側、Bが攻撃側**に入れ替わります。
  * 使用した防御カードのMP消費を確定し、Bの仮置き場カード数を `0` にリセットした上で、Aの防御フェイズ（物理なら `PHASE_DEFENSE`、奇跡なら `PHASE_MIRACLE_DEFENSE`）が再度起動します。
  * どちらかが被弾、または阻止（block）するまでこの攻守交代が繰り返されます。
* 防御側が弾きに失敗（50%の確率で自傷）した場合：
  * 解決は **「自分が自分に攻撃した（自傷）」** として処理されます（`Target = B, Attacker = B`）。
  * 攻撃に吸収効果（例: `＜吸収＞`）が含まれる場合、ダメージを受けた直後、同じ解決ステップ内でそのダメージ分回復します。HP5の時に攻撃力10の吸収付き攻撃を弾いて失敗した場合、HPは `5 -> 0 -> 10` となり、死亡判定の前に回復するため生存します。

## 4. 終末の時（Apocalypse）と悪魔の即時効果

対戦が長引いた場合、ゲームを収束させるための特殊フェイズ「終末の時」に移行します。

* **発動条件**: ターン数が **150 ターン以上**（`APOCALYPSE_TURN = 150`）に達した時。
* **基本システム**:
  - プレイヤーが新しくカードをドロー（ターンの補充ドローや「祈る」、地球神のドローなど全て含む）する際、**25% の確率で悪魔系カードがドロー枠に出現**し、その場で即時効果を強制適用します。
  - 悪魔の効果解決後、プレイヤーはその枠のカードを引くために**自動的に再ドロー**を行います（悪魔が連続して出現した場合はその都度効果が適用されます）。
  - 悪魔の効果適用によってプレイヤーのHPが0以下になった場合、即座に死亡判定（太陽のお守りによる復活、昇天弓による反撃）が走ります。

#### 悪魔系カードの出現率と即時効果

| 悪魔カード | 出現率 | 即時効果の内容 |
| :--- | :--- | :--- |
| **小悪魔** (small-devil) | 7% | 主人の HP が 10 減少する (HPの下限は0) |
| **中悪魔** (medium-devil) | 5% | 主人の HP が 20 減少する (HPの下限は0) |
| **大悪魔** (large-devil) | 3% | 主人の HP が 30 減少する (HPの下限は0) |
| **イタズラマン** (trickster) | 5% | 主人の手札からランダムに2枚を破棄する (手札が2枚以下の場合はすべて破棄) |
| **めぐみの妖精** (charity-fairy) | 5% | 主人の HP、MP、所持金 のうち、ランダムに1つが +10 される (上限は99) |
